

# Special Table-of-Contents Mode

This page is a table of contents.

- Extract every visible table-of-contents entry.
- Remove all dotted leaders and decorative dot sequences.
- Output each entry as a compact line: `section_number title page_number`.
- For chapter-level entries, output `chapter_number chapter_title`.
- For `Exercises`, output `Exercises page_number`.
- Use at most one short separator such as `...` if absolutely necessary.
- It is forbidden to output repeated `. . .` or long `.....` sequences.
- Do not preserve visual horizontal spacing.
- Do not spend tokens reproducing layout dots.
